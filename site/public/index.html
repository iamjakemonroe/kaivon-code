Questions

What does it cost?

The editor is free. Chip comes with a daily allowance on your free Kaivon account, the same account you use for Utopia and Chip Study, and it refills every day. It’s shared with Chip Study. Everyone gets Chip Fast; Chip’s best model, for the hard problems, comes with Pro (coming soon).

Why does my computer warn me when I open it?

Kaivon Code isn’t signed yet, which is common for a beta. It’s built in the open, so you can read exactly how on GitHub.

Mac: open the download, drag Kaivon Code to Applications and open it. When macOS stops you, go to System Settings, then Privacy & Security, and choose Open Anyway. You only do this once.

Windows: when “Windows protected your PC” appears, choose More info, then Run anyway.

Will my VS Code extensions work?

Most will. Extensions come from Open VSX, the open registry, because Microsoft’s marketplace is only for Microsoft’s products. A few Microsoft-only extensions, such as Pylance and Live Share, aren’t available. Open alternatives exist for most of them.

What does Chip see?

Only what it reads to do your job and the files you give it, and you can watch every file it opens. That goes to Kaivon’s server and on to Anthropic’s Claude to answer you. Chip can’t reach outside your project, and it asks before reading files that may hold secrets.

Which files can Chip read?

Your code and text, Excel workbooks with their formulas and macros, Word, PowerPoint, PDFs (scans too), images and more. Macros are read as text and never run. For a video, a program or anything else it can’t open, Chip tells you what the file is. Chip reads these files but can’t change them yet: it can write you a script that does.

Can Chip change my code without asking?

No. Each edit waits for your approval, and so does each command. If you’d like to move faster you can choose Apply all in this chat for edits. Commands always ask.

Who makes this?

Kaivon, the studio behind Utopia, Wavee and Chip Study. Kaivon Code is built on Code - OSS by Microsoft and the build work of the VSCodium project, and isn’t affiliated with either.
